# Manual del Usuario Operativo de Inventrix

Este manual explica, paso a paso, las funciones disponibles para el perfil Operativo (Tipo B). El usuario Operativo consulta existencias, registra entradas y salidas, y revisa el historial. No registra productos nuevos ni da de baja productos.

## Iniciar sesión
1. Abre la aplicación Inventrix.
2. Escribe tu Usuario (no tu correo) y tu Contraseña.
3. Si quieres comprobar lo que escribiste, toca "Mostrar contraseña".
4. Toca "Iniciar sesión".

Si los datos no son correctos, la app muestra "No fue posible iniciar sesión. Verifica tus datos." La sesión se mantiene en el teléfono; para salir, ve a Configuración y toca "Cerrar sesión".

## Navegar por la aplicación
La barra inferior tiene cuatro secciones: Inicio, Administración, Movimientos y Configuración. En Inicio ves el resumen de productos activos, las existencias por unidad y los movimientos recientes. Las existencias de unidades distintas (libras, cajas, etc.) nunca se suman entre sí.

## ¿Quién registra productos nuevos? El Administrador.
Los productos nuevos solo los registra el Administrador. Si un producto no aparece en la app, avisa al Administrador para que lo registre. Si escaneas un código que no existe, la app mostrará "Producto no encontrado. Solo el administrador puede registrar productos nuevos."

## Ver existencias
1. Ve a Administración y toca "Existencias".
2. Usa el campo "Buscar por nombre o código" o los filtros Todos, Disponible, Bajo y Sin existencias.
3. Cada producto muestra su estado: Disponible, Bajo inventario o Sin existencias.
4. Toca un producto para ver su ficha. Puedes consultar sus datos pero no editarlos.

## Registrar una entrada
Una entrada suma existencias, por ejemplo cuando llega mercancía.
1. Ve a Movimientos y elige entrada.
2. Busca el producto por nombre o código, o escanéalo.
3. Escribe la cantidad (debe ser mayor que cero). La app muestra las existencias resultantes.
4. Toca "Registrar entrada".

Verás "Movimiento registrado". Puedes tocar "Registrar otro movimiento" para seguir.

## Registrar una salida
Una salida resta existencias.
1. Ve a Movimientos y elige salida.
2. Busca o escanea el producto.
3. Escribe la cantidad y elige el "Motivo de la salida": Venta, Consumo interno o Retiro autorizado.
4. Toca "Registrar salida".

Si la cantidad es mayor que lo que hay, la app muestra "La cantidad supera las existencias disponibles." y no permite registrar. Si olvidas el motivo, aparece "Debes indicar el motivo de la salida."

## Escanear un código
1. En cualquier búsqueda de producto toca la opción de escanear.
2. Acepta el permiso de cámara con "Permitir cámara" la primera vez.
3. Apunta al código de barras o QR. Si hay poca luz toca "Encender linterna".
4. La app abre el producto o la pantalla de la acción que elegiste.

Alternativas: "Escribir el código manualmente" y luego "Buscar", o "Leer desde imagen" para tomar el código de una foto de tu galería.

## Qué hacer si el código no se reconoce
Si ves "Producto no encontrado.":
1. Revisa que el código esté completo y sin daños; vuelve a enfocar o enciende la linterna.
2. Prueba "Escribir el código manualmente" o "Leer desde imagen". Si dice "No se encontró ningún código en la imagen.", usa una foto más nítida.
3. Busca el producto por nombre en la lista de Existencias.
4. Si el producto no existe, avisa al Administrador: es quien lo registra.

## Exportar a Excel
1. Ve a Administración y toca "Existencias".
2. Aplica los filtros que necesites.
3. Toca "Exportar a Excel".
4. Elige dónde compartir o guardar el archivo (correo, WhatsApp, Drive, etc.).

## Historial de movimientos
En Movimientos abre el historial. Filtra por Todos, Entradas o Salidas y busca por producto o código. Al abrir un movimiento ves el usuario que lo hizo, la fecha, el motivo y las existencias antes y después. El historial no se puede editar ni borrar.

## Contactar soporte
Si tienes una duda o un problema, toca el botón flotante de soporte (el círculo con "?") que aparece en la esquina superior derecha de todas las pantallas. Se abre un chat de ayuda: escribe tu pregunta o elige una de las sugerencias y envía. El asistente responde con base en este manual; solo orienta y nunca modifica el inventario. Si el asistente no puede resolver tu duda, o hay un problema de conexión, aparece el botón "Contactar soporte por WhatsApp", que abre una conversación con el equipo de soporte con un mensaje ya preparado.
